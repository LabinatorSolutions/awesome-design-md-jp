01 / Weight

太さは font-weight ではなく書体名で切り替える

FOT-UD角ゴ_ラージ Pr6 R / M / B の 3 ファミリーを使い分ける。CSS に font-weight の宣言がなく、実測でも可視 284 要素のうち 280 要素が 400。font-weight: 700 を当てても太くならない（R のファミリーに太字の実体がない）。

ローカルでは FontPlus のドメインライセンスが効かないため、UD 書体として最も近い BIZ UDPGothic（モリサワ・Google Fonts）で代替している。BIZ UDPGothic は Regular と Bold の 2 本しかないので、M の位置には Noto Sans JP 500 を当てて 3 段を作った。

02 / Root & Line Height

ルートは 10px、line-height は 10px の絶対値

body { font-size: 62.5% } で 16px → 10px。サイズはすべて em で書かれ、1.4em = 14px として読む。さらに body の line-height: 1.0em は em なので 10px という絶対値になり、全子孫に降りる。

誤：line-height を書き忘れる

14px の文字に body の 10px の行送りが降りてくる。行が重なって読めない。実測でも行間比 0.71 の要素が 33 個ある（14.04px の文字に 10px の行送り）。

新規に組む要素には必ず line-height を書く。

正：各要素が em で宣言し直す

14px の文字に 1.6em = 22.4px の行送り。本文はこれが既定（実測 75〜81 要素）。見出しは 1.2em〜1.4em、長い説明文は 1.8em（19 要素）。

line-height を単位なしの比率に書き換えない。em の絶対値継承がこのサイトの前提。

html は 1440 / 1200 / 834 / 375px のいずれでも 16px 固定、body の 62.5%（= 10px）も全幅で動かない。流体ルートではない。縮むのは見出しだけで、em の宣言値を 834px / 375px で書き換えている。
