詰めずに、空ける

font-feature-settings の宣言は CSS 全文で 0 件（palt を使わない）。約物サブセットフォントも入れていない。代わりに letter-spacing を .1em と .2em の2段階でほぼ全要素に当てる（CSS 全文で .1em が 95 回、.2em が 50 回）。

letter-spacing: normal の要素はトップで 6 / 96、下層で 4 / 174 しかなく、その中身は Previous / Next / Launguage / English といった英語ラベルだけ。「日本語は必ず空ける、英語は触らない」という明確なルール。

約物は詰まらない。 palt も約物サブセットも無いので、「、。「」（）・」の前後には全角分の空きがそのまま残る。この状態の上に .2em を重ねるのが、このサイトの字面の作り方。palt を足すと約物が詰まり、字空けと喧嘩する。

300 / 400 / 700 の3段で組む

@font-face は Noto Sans JP の 300 / 400 / 500 / 700 の4本で、すべて loaded。ただし CTA の1つに font-weight: 900 が当たっている（ヘッダーの「法人様向けページ」）。900 の @font-face は無いので、ブラウザの合成太字で出る。

Noto Serif JP を 400/500/600/700 の4本読み込んでいるが、document.fonts で全部 unloaded・可視 0 要素。1文字も使われていないので、新規実装では @font-face を削ってよい。

896px で body ごと切り替わる
