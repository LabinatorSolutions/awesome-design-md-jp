ウェイトは 300 / 400 / 500 / 600 の 4 段（700 は下層に 1 要素だけ）。Noto Sans JP も DM Sans も可変フォントなので中間値も実在する。「見出しほど太い」設計ではない——42px の見出しが 400、24px のサブ見出しが 500 になる場面がある。

字間は em を各要素に当てる

既定0.08em。48px → 3.84px、36px → 2.88px、18px → 1.44px、16px → 1.28px、14px → 1.12px、12px → 0.96px
小さい UI0.01em（最小のボタン）/ 0.04em（日付・フッター）/ 0.045em（グローバルナビ）/ 0.05em（キャプション）
負の値-0.02em（欧文の大きな見出し）/ -0.12em（装飾の数字）
読み方分布に 3.84 / 2.88 / 2.56 / 1.92 / 1.44 / 1.28 / 1.2 / 1.12 / 0.96px が並ぶのは、サイズが違えば px も違う＝各要素が em を持っている証拠。「px で継承されている」と読まない
字詰め下層は body に font-feature-settings: 'palt' on を 1 行（実測 1047 要素）。トップはコンポーネント単位で 51 箇所（実測 202 要素）と正反対。新規実装では body に 1 行で足りる
折り返し下層のみ word-break: break-word。break-all と違い 1 行に収まらない語だけを折る（トップは normal）

グラデーションで地を作る

linear-gradient(1.72deg, #DAE2EA 15.13%, #ECF0F3 54.34%, #F9F9F9 70.26%, #E5EAF0 88.37%)

角度 1.72deg・停止位置 15.13% / 54.34% / 70.26% / 88.37% は丸めずそのまま写す。box-shadow の実測は両ページとも 0 種で、階層は「面の色」「1px の枠線（#DDE0E7）」「グラデーション」の 3 つだけで作る。

再現するときの注意

2 世代のテンプレートトップは html 16px、下層は 10px。palt の配り方も宣言位置も違う。1 ページだけ測るとルートを取り違える。新規実装は下層の流儀に揃える
Helvetica の重複トップの font-family は … "Helvetica Neue", Helvetica, Helvetica, Arial …（可視 252 要素）。2 回目は到達しない。正しくは 1 回
<a> の色実サイトは <a> に color の宣言が無く、ロゴの画像リンクと読み上げラベルが UA 既定の #0000EE のまま（可視 19 要素）。画像リンクなので実害は無いが、テキストを直下に置くと青が出る
ブランドの紺#0E0D6A の実測は両ページ合わせて 3 要素。面に広げない。このサイトの印象は #222222 の文字と角丸 8px の白い面が作っている
流体全面的な流体ではなく、min() / clamp() を部品ごとに当てる。min(18px, calc(18 / 1372 * 100vw)) の分母 1372 が SP の基準幅
