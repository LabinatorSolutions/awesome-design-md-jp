ウェイトは「太さ」ではなく「書体の選択」。Adobe Fonts の 3 書体はそれぞれ単一ウェイトで配信されている（見出ゴ MB31 = 600 / Rig Shaded = 700 / 凸版文久見出しゴ = 900）。見出ゴ MB31 に 700 を当てるとブラウザの合成太字になり字形が崩れる。

Rig Shaded は欧文専用。スタックは rig-shaded-bold-face, sans-serif で和文グリフを持たないため、同じ要素に日本語が混ざると和文だけ OS 既定に落ちる。実サイトの English 簡体中文 がそれで、意図的に欧文だけ装飾している。

字間は html に 1 回だけ。子要素で letter-spacing を再宣言しないこと。14px × 0.08em = 1.12px が px のまま降りるので、サイズの違う要素でも同じ 1.12px になる。それがこの設計の意図。

Adobe Fonts が揃うまでページ全体を隠す。実サイトは html { visibility: hidden } ／ html.wf-active { visibility: visible; animation: fadeIn 1s }。Typekit が wf-active を付けるまで白紙になる。再現する場合は取得失敗時の保険を併せて実装すること。
