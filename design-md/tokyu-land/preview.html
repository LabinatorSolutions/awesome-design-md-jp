YuGothicM（local のみ）0unloaded が正常（下記）

游ゴシックの Windows 対策を local() だけの @font-face で書いている。

@font-face { font-family: YuGothicM; src: local("Yu Gothic Medium") } を定義し、スタックの YuGothic の直後に置く（別名方式）。素の YuGothic は macOS で游ゴシック体 Regular に当たり、Windows では家族名が Yu Gothic（スペース入り）なので当たらない。そこで Windows だけが YuGothicM → Medium を拾う。
src が local() だけなのでダウンロードは発生せず、document.fonts 上では永久に unloaded のまま。これは失敗ではなく正常な挙動で、「使われていない」と読み違えないこと。
ただしこのサイトでは効く場面が無い — スタック先頭の Noto Sans JP が loaded するので游ゴシックまで降りてこない。別名方式そのものは正しいので、Web フォントを使わない案件で流用する価値がある。

Responsive

body は動かない。1440 / 1200 / 834 / 375px の 4 幅すべてで 16px / line-height 1.70 / letter-spacing normal のまま。流体（vw / clamp）も SP での縮小も無い。html は 10px 固定なので rem は 10 倍で読む（2.88rem = 28.8px）。
