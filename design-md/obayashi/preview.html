01 / Colors

ブランド色は「塗る色」ではなく「引く線」

コーポレートグリーン #018A0E は CSS 全文で 21 回現れるが、静止状態で描画される要素は 0 個。 グローバルナビ項目の ::before（height: 1px / opacity: 0）として仕込まれ、ホバーとカレント表示でだけ現れる。 上のナビ「事業」に引かれている 1px の緑線がそれ。面は 白・淡グレー・フッターの #565656 しか使わない。

02 / Typography

字間は書かない。詰めるのは約物だけ

スタックの先頭に YakuHanJPs（約物だけのサブセット書体）を置き、2 番目に 游ゴシック Medium の別名 MyYuGothicM を置く。 letter-spacing は実測 353 要素中 346 要素が normal、font-feature-settings は 0 件。 サイズはすべて rem だが、px を 16 で割って小数 2 桁に丸めているため 14.08px / 13.12px / 38.08px という半端な実測値になる。

詰めているのは約物（かっこ・句読点・中黒）だけで、かなと漢字の間は詰まらない。 palt と違って OS やブラウザで結果が変わらない反面、letter-spacing を足すと約物が二重に詰まって崩れる。 MyYuGothicM の @font-face は local() だけで書かれており、游ゴシックが無い環境では status: error になってヒラギノへ落ちる。これは意図どおりで、URL を足してはいけない。

03 / Article

本文は 1rem / line-height 1.8、読み物は 800px

大林組がめざす姿、社会において果たすべき使命を示したものが「大林組基本理念」です。

三箴（さんしん）

「良く、速く、廉く、しかも安全に」——創業以来受け継がれてきた言葉を、いまの事業のことばに置き換えて示しています。 本文は 1rem（16px）／line-height: 1.8。ナビゲーションやリストの 1.7 より一段ゆるく組み、読み物であることを行間で示します。

  • 優れた技術による誠実なものづくりを通じて、空間と環境の価値を高める
  • 地球環境に配慮し、良き企業市民として社会の課題解決に貢献する
  • 公正・透明な企業活動を徹底し、社会からの信頼に応える

箇条書きの行頭記号は円ではなく 6px の正方形。このサイトは border-radius を持たないので、リストマーカーも角のままにします。

04 / Buttons & Badges

面で塗った CTA が無い

押せるものは「白地に #cad0d5 の罫で囲む」か「#272727 の黒面」の 2 種類だけ。 どちらも border-radius: 0、box-shadow: none。ホバーは色を #d6dade / #666666 に差し替える。 ニュース種別のバッジは面 #eff0f2・文字 #272727 で共通、種別色は ::before の 左端 4px の帯にだけ塗る。 暗い面では面が #585858・幅 190px・帯 5px の別バリアントになる。

05 / Cards

07 / Depth & Elevation

影は無い。奥行きは罫線と明度差で作る

実測 2 ページで box-shadow は 0 種類、border-radius も 0 種類。 段差は #cad0d5 の 1px 罫と、#ffffff → #eff0f2 → #f1f2f4 → #565656 という面の明度差だけで表す。
