02 / Sizing
Percent Scale

サイズを px ではなく % で組む

CSS 全文で font-size: % が 226 箇所、px は 87 箇所。1px 刻みを % に換算した梯子が並ぶ。子をすべて % / em で書いてあるから、ラッパー 1 箇所を書き換えるだけでページ全体が連動して拡大する。実測サイズに 14.08px 21.3328px 29.8656px といった端数が並ぶのはこの入れ子の掛け算の結果。

86.66%13px 相当126.66%19px 相当
93.33%14px 相当133.33%20px 相当
100%15px 相当（基準）140%21px 相当

font-size を px で書かない。px で書くと文字サイズ切替が効かなくなり、このサイトの設計そのものが壊れる。同じ理由で line-height も比率（無単位）で書く。

お知らせだけ縦組み

縦組みは 3 要素だけ、すべて本物のテキスト（画像でもウィジェットでもない）。トップページの「お知らせ」で、39px 幅の左カラムに見出しと 一覧を見る を縦に積んで立てている。下層ページには無い。

実サイトは 39px 幅の左カラムに見出しと 一覧を見る を縦に積み、その右に一覧本体を置く（実測: 見出し left=120 / top=939、リンク left=126 / top=1091）。
縦組みを「横に並べる」ときだけ flex-direction: row-reverse が要る。素の display: flex だと DOM 順に左→右へ置かれ、日本語の縦組みとして読む向き（右→左）と逆になる。ここは縦に積んでいるので素の flex でよい。
