Color

館に色を持たせず、展覧会に色を割り当てる

ブランドカラーが存在しない。代わりに6色のカテゴリカラーがあり、展覧会・イベントごとに1色が割り当てられる。CSS 全文での出現回数がほぼ揃っている（12〜15 回）のは、6色が同じ役割の体系として書かれている証拠。

色の指定は CSS 変数を介さず、クラス名が color_ ＋ hex そのもの（.color_039788）。CSS Custom Properties は実サイトに 0 個。

Typography

書体は1本。差は太さとサイズでつける

可視テキストの全要素が YakuHanJP, "Noto Sans Japanese", sans-serif（トップ 168/168、下層 108/108）。見出しも本文もナビも同じ1行で組み、太さとサイズだけで階層を作る。

YakuHanJP は unicode-range で約物だけに限定したサブセットフォントで、Google Fonts に無いためこのプレビューでは再現できない。実サイトでは「、。「」（）・：；？！」が詰まって出る。font-feature-settings の宣言は CSS 全文で 0 件＝palt は使っていない。

Font Weight

使えるのは 100 / 200 / 400 / 700 の4本だけ

CSS は @font-face を 100 / 200 / 300 / 400 / 500 / 700 / 900 の7本宣言しているが、document.fonts に載るのは 100 / 200 / 400 / 700 の4本だけ。CSS が当てている 500（実測 37 要素）と 900（実測 4 要素）は、指定どおりの太さで出ていない可能性が高い。

読み込まれるウェイトはページごとに違う。トップは 100 が loaded / 200 が unloaded、下層はその逆。ページに現れた字形しか読み込まれない。
