02 / Typography

UD 書体 1 本

和文は BIZ UDPGothic（モリサワの UD 書体・プロポーショナル版）のみ。可視 155 / 79 要素のうち 155 / 79 要素がこれで、残り 1 要素だけが欧文の Poppins。Google Fonts から wght@400;700 の 2 ウェイトを配信している（フォント要求 60 件）。UD 書体は字面が大きく、濁点・半濁点が離れていて、1 7 l の判別が付きやすい。

"Local BIZ UDPGothic" は実体が無い

実サイトは font-family: "Local BIZ UDPGothic", "BIZ UDPGothic", sans-serif と書いているが、CSS 全文の @font-face は webicon の 1 件だけで、Local BIZ UDPGothic を定義するものはどこにも無い。document.fonts にも載らない。先頭名は必ず外れ、2 番目の Google Fonts 配信に落ちている。OS 同梱の BIZ UDPGothic を優先してダウンロードを省く意図だったと思われるが、効いていない（フォント要求は 60 件発生する）。

書き方結果
font-family: "Local BIZ UDPGothic", "BIZ UDPGothic", sans-serif;実サイト。先頭は外れ、Google Fonts の BIZ UDPGothic が当たる
@font-face { font-family: "Local BIZ UDPGothic"; src: local("BIZ UDPGothic") }本来必要だった宣言（実サイトには無い）
font-family: "BIZ UDPGothic", sans-serif;★新規実装はこれだけでよい

欧文の Poppins はフッターのコピーライト 1 要素だけに使われている。実サイトの宣言は Poppins, serif で、サンセリフなのにフォールバックが serif（正しくは sans-serif）。さらにその要素の font-weight は 400 だが、Google Fonts からは Poppins:wght@600 しか配信していないので、ファミリーに 1 本しか無い 600 が出る。

字間は body に 1 回。見出しだけ上書きする

05 / Elevation

落ち影がない。あるのはリング

実測された box-shadow は rgba(37,57,87,.3) 0 0 0 8px の 1 件だけ。オフセット 0・ぼかし 0・広がり 8px なので、これは影ではなくブランド紺の輪。下層ページは box-shadow が 0 種。

rgba(37,57,87,.3)
0 0 0 8px

浮きは 1px solid #dee1e6 の枠と #eeeff2 の地色で作る。新規実装で落ち影を足すと、このサイトの平らさが失われる。

06 / Layout

html が vw で動く

設計幅は 1080 / 860 / 390px の 3 つで、各レンジの中は レイアウト全体が viewport 幅に比例して伸縮する。どのレンジでも、その設計幅ちょうどで html が 10px に着地する。

9.615px / 21.385px / 12.547px のような半端な値が出たら、html が vw で動いている合図。1 幅だけ測って「このサイトの本文は 16px」と書かない。rem 指定は維持し、px へ読み替えない（読み替えると 390px 以外の全幅で崩れる）。
なお ≤859px の規則が 859px まで効くため、タブレット縦（768〜859px）で本文が 27〜31px まで巨大化する。390px 設計のモバイルレイアウトをそのまま引き伸ばしているため。新規実装では clamp() で上限を切るか、タブレット用の規格幅をもう 1 段挟む。
