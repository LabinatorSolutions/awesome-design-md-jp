02 / Typography
Typography
字間を一切触らない

可視 173 要素中 170 要素が letter-spacing: normal（下層は 55/55 ＝ 全部）。CSS 全文でも宣言は 0.1em / 0.2em / 0.01em / 0.4em の 4 つしかなく、本文には 1 つも当たっていない。例外は部門名の 3 要素（24px に 0.1em ＝ 2.4px）だけ。font-feature-settings も 0 要素で、Noto Sans JP の既定の字送りのまま組む。

文字サイズが全段 clamp() の流体

html は 16px 固定だが body 自体が --text-md。4 幅で測ると 1440px → 16px / 1200px → 15.968px / 834px → 15.0896px / 375px → 14px と連続的に動く。px で書き写すとブレークポイント間で別物になる。

05 / Elevation
Depth & Elevation
影は 3 段のトークン
