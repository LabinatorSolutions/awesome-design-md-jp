02 / Typography

太さはファミリー名で切り替える

和文はモリサワ「新ゴ」の 2 ウェイトを TypeSquare（wf.typesquare.com）で配信している。注入される @font-face は 4 本すべて font-weight: bold（新ゴ R / Shin Go Regular / 新ゴ DB / Shin Go DeBold、いずれも loaded・unicodeRange: U+0-10FFFF）。ファミリーに実体が 1 本しか無いので、CSS が 400 でも 700 でも同じファイルが返る。

このプレビューでは Adobe / モリサワのドメインライセンスのため新ゴを表示できない。同じモリサワ系で字面の近い Zen Kaku Gothic New（Google Fonts）で代替し、--font-r / --font-db という 2 つの変数に分けて「ファミリー名で切り替える」構造だけを再現している。

CSS の書き方実サイトの挙動
font-family: "新ゴ R"; font-weight: 400;新ゴ Regular が出る（正しい）
font-family: "新ゴ DB"; font-weight: 700;新ゴ DeBold が出る（正しい）
font-family: "新ゴ R"; font-weight: 700;新ゴ Regular のまま。太くならず、合成太字も起きない
font-family: "新ゴ DB"; font-weight: 400;新ゴ DeBold のまま。細くならない

目印は フォント要求の typesquare.com / wf.typesquare.com と typesquare.js の読み込み（実測 5 件）。欧文の HelveticaNeueeTextPro-* は Web フォント配信されておらず、実機に無ければ Helvetica Neue 以降へ落ちる。

字間を設計に入れていない

可視 137 要素中 121 要素が letter-spacing: normal（下層は 133 中 114）。font-feature-settings も 0 要素で、約物も詰めない。開けるのはフッターリンク（1px）とグローバルナビ（0.288px ＝ 16px × 0.018em）だけ。

04 / Forms

入力は角丸なし

border-radius: 0 / 1px solid #bbbbbb / padding: 0 15px / 15px。input はフォント継承が効かないので font-family を明示的に当て直す。

05 / Elevation

影は 1 種類、しかも輪郭が見えない

実測された自前の box-shadow は rgba(0,0,0,.07) 0 3px 60px 0 の 1 件だけ。blur: 60px / alpha: 0.07 と極端に広く薄いので、落ち影というより面の下の空気のように見える。

rgba(0,0,0,.07) 0 3px 60px 0 トップのカルーセル枠にだけ使われている。ほかの要素はすべて none で、区切りは 1px solid #dddddd の枠が担当する。

もう 1 件測れる rgba(0,0,0,.2) 0 0 18px は OneTrust の Cookie バナーのもので、サイトの設計ではない。

06 / Layout

html は 10px 固定、body だけが 2 段で流体

html は 4 幅すべて 10px 固定（62.5% 相当）。動くのは body の方で、タブレット域とスマートフォン域で別々の vw 式が当たっている。
