body に letter-spacing: 0.04em を書き直してはいけない。em を body に書くと 16px × 0.04 = 0.64px が全サイズに固定継承され、12px の注記（実サイトは 0.48px）が相対的に空きすぎる。実サイトはサイズに比例させている。例外は数字（3,000 2,000）の normal（13 要素）。

font-weight: 800 / 900 を書かない。読み込んでいる Noto Sans JP / Noto Sans は可変フォントの wght@400..700で、レンジ外は 700 にクランプされる。実サイトのヒーロー見出し（900）とキャンペーン帯（900・9 要素の 800）がそれ。Poppins の 600 も unloaded なので使わない。

palt は 1 要素も無く、CSS 全文にも 0 回。字詰めは letter-spacing だけで作る。word-break の宣言も CSS 全文で 1 回だけで、改行位置は HTML 側の <br> で決めている。

06 / Layout
Layout

コンテナ 1152px / gap は 10・12 と狭い

ブレークポイントは max-width の宣言が圧倒的（768px が 213 / 255 件、1024px が 90 / 110 件）。デスクトップ基準で下へ上書きする設計で、モバイルファーストではない。

--container: 1152px（下層 15 回で最多）
1000px（トップ 7 回）
312px（カード）

html / body は 4 幅（1440 / 1200 / 834 / 375px）すべて 16px 固定。rem 換算は常に 16px 基準でよい。見出しだけメディアクエリで切り替わり、字間は 0.04em のまま追従する（32px → 1.28px、24px → 0.96px）。
