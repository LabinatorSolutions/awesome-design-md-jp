大倉陶園のホワイト

“セーブルのブルー、オークラのホワイト”

創立以来「良きが上にも良きものを」の志を理念とし、原料・成形・焼成のすべてに手を抜かずにきました。 製品は “セーブルのブルー、オークラのホワイト” と並び称され、独自の白さで知られています。

本文は 16px / line-height: 1.73、字間は normal。 「間」は行間と余白が作るので、letter-spacing を足す必要がありません。 見出しの背後には ::after で 1px の罫を全幅に引き、文字の後ろだけ白で抜いています。

CTA は 1 種類。面で塗らない04 / Buttons

白地に 1px solid #24315a の枠、高さ 3em（48px）、幅 16.75em（268px）、border-radius: 0。 右下に 4px ずらした L 字の罫（border-width: 0 1px 1px 0）が影の代わり。 ホバーでは ::before の幅が 0 → 100% に伸び、紺が左から満ちて文字が白へ反転する。
