02 / Typography

丸数字のために @font-face を 9 本

本文スタックの先頭に NotoSansJP-circled-1〜-9 が並ぶ。それぞれ unicode-range が ①〜⑨ の 1 文字ずつ（U+2460〜U+2468）に絞られていて、該当文字が無いページでは1 バイトも取りに行かない。セルフホストしている NotoSansJP-Regular.woff2 のサブセットに丸数字が入っていないための補填。

階層 1 は 0 3px 6px rgba(0,0,0,.1) に一本化されている。カードは全部これ。浮かせたいものだけ影の色を rgba(48, 54, 62, 0.1)（本文色の 10%）にして、黒い影より面に馴染ませている。10 周年バナーは 0 1px 5px rgba(48,54,62,.1), 0 5px 9px rgba(13,100,201,.1) と青の影を重ねている。filter: drop-shadow() / text-shadow は 0 件。

Responsive

ブレークポイントはすべて min-width で書かれたモバイルファースト。max-width は 1 件も無い。320 / 375 / 605 / 767 / 768 / 798 / 1230 / 1280 / 1325px。screen and (min-width: 768px) and (min-width: 1280px) という入れ子のまま出ている指定もある（実質 1280px）。

html は 16px 固定、body は 1440 / 1200 / 834px で 16px、375px で 14px。行間は 1.6 のまま（25.6px → 22.4px）、字間は 0.1em なので 1.6px → 1.4px に自動追従する。見出しも連動し、h1 は 60px → 42px、h2 は 40px → 23px（字間は 1.6px → 0.92px = 0.04em のまま）。
body のサイズを落とすだけで、字間も行間も見出しも比率で追従する設計。px に読み替えると、この自動追従が全部壊れる。
ヘッダーの CTA は高さ 38px で WCAG の 44px を下回るので、新規実装では 44px 以上を確保すること。
