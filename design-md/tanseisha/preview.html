01 / Colors
Color

社名の 2 文字が、そのまま配色になっている

clamp() の流体タイポ

html は 10px 固定で、動くのは body 以下。768px で 15px、1200px で 16px を線形補間する。傾きは厳密に 1px / 432px（= 1200 − 768）。768px を下回ると流体が止まり、行間も 2.0 → 1.8 に落ちる。

CSS では clamp(1.2rem, .8444444444rem + .462962963vw, 1.4rem)（12px→14px）のように書かれている。.462962963vw × 432px = 2px で、すべての clamp が 768〜1200px の窓で設計されている。letter-spacing と line-height を px で書き写すと、この帯域で比率が崩れる。

font-feature-settings: "palt" は CSS に 7 回あるが、この 2 ページでは 1 要素も効いていない。セレクタがすべて .main--partner*（協力会社向けページ）に限定されていて、グローバルナビでは font-feature-settings: normal で明示的に打ち消してすらいる。コーポレート画面に palt を足さないこと。使う場合は実サイトと同じく letter-spacing: .08em とセットにする。
