ウェイトは 400 と 700 の 2 段だけ。実測で 500・600 は 1 要素も無い。Web フォントが無いため、使える太さが OS 同梱書体の持ち分に限られる。中間の太さを足すと合成されてしまう。

字間は normal。実測 93/93 要素（トップ）・48/48 要素（下層）で例外なし。font-feature-settings: "palt" も CSS 全文で 0 件。

Line Breaking

禁則処理を切っている

body { word-break: break-all } を 7 幅すべてで確認。distributions には出ないので、body の computed style を直接見ないと気づけない。

和文だけの文章では差が出ない（CJK は既定でどこでも折れる）。違いが出るのは欧文の単語と行頭禁則で、break-all は行末に収まらない欧文を単語の途中で切る。下は同じ文・同じ幅での比較。
