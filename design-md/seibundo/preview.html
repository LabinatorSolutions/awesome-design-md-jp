01 / Colors

ブランド色は「新刊」と「近刊」の2色だけ

面として広く塗る色を持たない。#ff5224（新刊・面 45 要素）と #00a7e5（近刊・面 19 要素）は 書影のバッジ以外に出てこない。黒が #000000 / #111111 / #222222 の 3 段あるのは、 リセット CSS の body { line-height: 1; color: #000 } と本体 CSS の color: #111 が二重にかかっているため。

02 / Typography

Web フォントを1本も読み込まない

common.css には Roboto と Noto Sans JP の @font-face が 9 件書かれているが、 /*font*/ の後ろがまるごとコメントアウトされている。 実測でもフォントファイルのリクエストは 0 件、document.fonts は空だった。 Roboto, sans-serif が 10 要素に当たっているが、実体は OS の既定サンセリフ。 html に font-size の宣言も無く、ブラウザ既定の 16px のまま使っている。

03 / Vertical Writing

ジャンル見出しは縦組み

/book/ の 12 ジャンル見出しが writing-mode: vertical-rl。 游ゴシック体 20px / line-height: 20px（ベタ組み）/ 700 で、字間は normal のまま。 @media screen and (max-width: 768px) で horizontal-tb に戻すので、 縦組みはデスクトップだけの表現。「コンピューター・ＩＴ」のように全角英字を使って縦中横を避けているのが実装上の工夫。

04 / Buttons & Badges

ボタンは丸く、バッジは角のまま

押せるものは border-radius: 30px の pill（実測 70 要素）。 バッジは border-radius: 0。押せるものと押せないものを形で分けているので、 「新刊」「近刊」を丸めてはいけない。角のままのボタンはグレーの #cccccc 1 種類だけ。

中間の角丸を持たない。実測の border-radius は 30px（70 要素）と円（50% / 99%）だけで、 4px や 8px は 1 件も無い。

08 / Layout & Responsive
