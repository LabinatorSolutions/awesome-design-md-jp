02 / Typography

可視テキスト 296 / 253 要素すべてが "Noto Sans JP", sans-serif。CSS 全文の font-family 宣言もこの 1 種類だけで、明朝も欧文専用書体も存在しない。font-feature-settings: "palt" が 1073 要素、letter-spacing: .05em が CSS 全文で 454 回。

04 / Forms

入力は下線だけ

サイト内検索のみ。枠線も角丸も持たず、下線とアイコンで構成する。input はフォント継承が効かないので font-family を明示的に当て直す。

05 / Elevation

影が 1 つも無い

実測された box-shadow は rgba(0,0,0,.2) 0 0 18px 0 の 1 件だけで、それも OneTrust の Cookie 同意バナーのもの。サイト本体に自前の影は存在しない。

LevelShadow用途

浮きは 角丸 16px ＋ 地色 #f5f5f0 で作る。新規実装で影を足すと、サイトのフラットさが失われる。
