02 / Typography

1rem = 24px。字間は body に 0.05em を1回だけ

html { font-size: 24px } を実際に宣言している。1440 / 1200 / 834 / 375px の 4 条件で計測してすべて 24px 固定。 body の letter-spacing: 0.05em は 24px 基準なので計算値 1.2px になり、 11px の注記から 40px の見出しまでサイズが違うのに全部 1.2px（可視 247 要素中 131 要素）。 和文書体は Zen Kaku Gothic New の一本で、本文のウェイトは 500（154 要素）。

letter-spacing: 0.05em は body に 1 回だけ書いて継承させる。 子要素で書き直すと、そこだけサイズに比例して字間が変わり、継承した 1.2px と揃わなくなる。 実サイトで個別に当てているのは 8 箇所（0.75px / 2.25px / 1.4px / 2px / 3px など）だけ。 font-feature-settings は 0 要素。palt を足すとカタカナのサービス名が詰まって別物になる。

03 / Article

読ませる段落だけ行間を 1.6 → 2.0 に広げる

「こんな暮らしが欲しかった！」を、誰にでも。

既定の行間は 1.4（135 要素）。読ませたい段落だけ 1.6（75 要素）、 さらに長い説明文で 2.0（9 要素）と、3 段階だけ持つ。 本文でも font-weight: 700 を使うのがこのサイトの流儀で、400 は 17 要素しか無い。

  • 物件探しから設計・施工までワンストップで進められる
  • 内装仕様も間取りも自由なオーダーメイドリノベーション
  • 内装仕様は厳選済み・間取り自由のセレクテッドリノベーション

箇条書きの行頭記号は 9px の円。角丸が 8 種類あるこのサイトでは、丸が基本の形になる。

07 / Depth & Elevation

影は実測 1 要素。奥行きは角丸と面色で作る

box-shadow は 2 ページの実測で 1 種類・1 要素だけ。 段差は #ffffff → #f2f2f2 → #f5f5f5 → #ddeaed の面色と、 4px → 10px → 16px → 999px の角丸で表す。

Level 0 — ほぼ全要素
box-shadow: none
Level 1 — 実測 1 要素だけ
rgba(149,157,165,.2) 0 8px 24px 0

rgba(149,157,165,.2) 0 8px 24px は広く出回っている汎用値で、このサイトの署名的な影ではない。多用しない。
