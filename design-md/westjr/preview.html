影は 1 種類の値（10px 10px / 0.16）を、向きだけ反転して使っている。役割は「浮かせる」ではなく「重なりの向きを示す」。上に重なる要素は上向き、上から降りる帯は下向き。ぼかしと濃さは同じ。filter: drop-shadow() / text-shadow は 0 件。

Responsive

html 10px / body 16px / line-height 27.2px / letter-spacing 0.8px は 4 幅すべてで同じ。流体も SP 縮小も無い。モバイルで変わるのは見出しだけ（例: 列車運行状況 が 16px → 375px で 17px）。下層の p, li, th, td は 4 幅すべて 17.2308px のまま。

主分岐は 768px。トップ（新デザイン）は min-width: 1280px でデスクトップを足し、下層（2018 年版）は max-width: 767px（154 件）でモバイルを削る、という逆向きの書き方が同居している。
下層の CSS は print, screen and (min-width: 768px)（62 件）のようにほぼすべてのメディアクエリに print を併記しており、印刷時にデスクトップ幅のレイアウトを使う。公共インフラらしい配慮。
c-button-small は高さ 28px で WCAG の 44px を下回るので、新規実装では 44px 以上を確保すること。
