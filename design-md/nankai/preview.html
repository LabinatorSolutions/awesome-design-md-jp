ウェイトは 400 / 500 / 700 の 3 段だけ。Google Fonts の要求は wght@400;500;700 で、実測の分布も 400（154）/ 700（71）/ 500（35）。600 や 300 を当てると合成になる。

font-feature-settings: "pkna" を :root に 1 回だけ書いて可視 1765 要素へ継承させている。palt ではない。pkna はかな（ひらがな・カタカナ）だけをプロポーショナル字形にし、約物・漢字・欧文の幅は動かさない。palt より詰まり方が穏やかで、読み違いが許されない案内文に向く。

行間は 1.5 の一本。--line-height--root: 1.5 を body { line-height: inherit } で受け、可視 255 要素が 1.5。見出しで詰めない。見出しの締まりは font-size と余白で作る。

フォールバックは sans-serif だけ。実サイトは "Noto Sans JP", sans-serif しか書いておらず、OS 書体への保険が無い。新規実装では "Noto Sans JP", "Hiragino Sans", "Yu Gothic Medium", sans-serif のように挟むとよい（実サイトはそうしていない）。

ブレークポイントは min-width: 769px が主軸（CSS 内 7 回で最多）。569 / 1025 / 1281 / 1600px が続く。@media print, screen and (min-width: 769px) の形が多く、印刷にもデスクトップレイアウトを当てている。@media (prefers-reduced-motion: reduce) も実装済み。html は 4 幅すべてで 10px 固定で、本文のタイポグラフィはブレークポイントをまたいで同一。
