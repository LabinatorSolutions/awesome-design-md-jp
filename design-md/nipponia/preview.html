03 / Vertical
Vertical

縦組みは、右端のタブだけ

実サイトで writing-mode: vertical-rl が当たっているのは 6 要素（うち 2 件はアイコンの <svg> / <use>）。右端の固定タブと、サブメニューの「私たちの想い」だけだ。ヒーローの大きな縦組みコピーは実装ではない。

お問い合わせ
視察・求人・物件
本物の縦組み。幅 40px・line-height: 40px の絶対値・letter-spacing: normal。主ラベルが 14px、副ラベルが 10px。

複数の縦組みを横に並べるときは flex-direction: row-reverse にする。素の display: flex だと DOM 順に左→右へ置かれ、日本語の縦組みとして読む向き（右→左）と逆になる。

ヒーローのコピーは SVG スプライト。.TopSlideCopy__inner > svg > use[xlink:href="#icon-top-copy"]（154×490px）で、<text> 要素は 0 個、<path> も 0 個のアウトライン。document.images にも verticalWriting にも出てこないので、スクショだけ見て「縦組みを実装している」と判断しないこと。下は同じ見え方を SVG で再現したもので、実サイトの構造に合わせてある。
