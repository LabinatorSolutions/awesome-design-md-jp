02 / Typography

Web フォントを 1 本も読み込まない

Typography

実測でフォントファイルの要求が 0 件。@font-face もトップには 1 つも無い。游ゴシック／ヒラギノ／Segoe UI という OS ローカル書体だけで組むこと自体が設計で、画になる部分（ヒーローの欧文ロックアップ・波形のマスク）は画像に逃がしている。

Windows の游ゴシック問題を「スタック順」だけで解く

@font-face による別名定義も上書きもせず、游ゴシック体, YuGothic の次に "游ゴシック Medium", "Yu Gothic Medium" を置く。Windows には 游ゴシック体 も（スペース無しの）YuGothic も存在しないので 3〜4 番目が当たる。副作用として macOS は Regular、Windows は Medium になり太さが揃わないので、厳密に揃えたい案件では src: local("Yu Gothic Medium") の別名方式を使うこと。

① 既定（body）— 欧文を OS システム書体に寄せる
-apple-system, BlinkMacSystemFont, Roboto, 游ゴシック体, YuGothic, "游ゴシック Medium", "Yu Gothic Medium", 游ゴシック, "Yu Gothic", "Noto Sans JP", "Hiragino Sans", "Segoe UI", sans-serif
② 和文優先（.def-jpfont）— 欧文も游ゴシックのグリフで統一する

body の line-height が 1

行間はブロックごとに明示的に与える設計。「何も指定しない要素は行間ゼロ詰め」という前提で組まれているので、テキストを持つブロックには必ず line-height を書く。

font-weight は 400 と 700 の 2 段だけ（実測 400 が 97 要素 / 700 が 85 要素）。游ゴシックは Regular と Bold の 2 本しか無いので、500 や 600 を指定すると Windows で合成太字になる。

05 / Elevation

カードの影は x に 1px ずれる

Depth & Elevation

カードの影は 1px 3px 6px rgba(0,0,0,0.1)（33 要素）。x に 1px のオフセットがあるのが特徴で、0 3px 6px に丸めると印象が変わる。ヘッダーだけ x ずれなしの 0 3px 6px。CTA には影を落とさない。

Level 0（ボタン・ピル）
none

1px 3px 6px rgba(0,0,0,0.1)
Level 2（ヘッダー）
0 3px 6px rgba(0,0,0,0.1)

抽出でもう 1 つ検出される rgba(0,0,0,0.3) 0 -4px 10px は Cookie 同意バー（CMP）のもので、サイト本体の語彙ではない。

06 / Layout

コンテナは 1140px の 1 値だけ

Layout

実測で検出されたコンテナ幅は 1140px（8 要素）のみ。余白のスケールも宣言されておらず、gap は 0px 2.645% という % 指定。html が 62.5% ＝ 10px 基準なので、rem は「px の 1/10」として読む（2.8rem = 28px）。
