このプレビューの代替書体について。本番の あおとゴシック L / DB はドメインライセンスのためローカルで表示できないので Zen Kaku Gothic New で代替している。実サイトの font-weight は 400 だが、代替書体の 400 は あおとゴシック L より明らかに太いため、このプレビューだけ 300 を当てている（左側の表記「400」は実サイトの値）。

letter-spacing は normal が既定（トップ可視 185 要素中 177 要素、下層 76 要素中 75 要素）。それでいて font-feature-settings: "palt" がトップで 3309 要素に効いている。「字間は足さないが、約物の空きは詰める」。どちらか片方だけ真似しないこと。

line-height が em 単位で宣言されている。16px の親に 1.7em と書くと 27.2px という絶対値が降り、12px のフッターリンクでは実測比 2.27 になる。単位なしの 1.7 に書き換えると別物になる。

見出しに line-height を指定していない。h1 44px・h2 30px・ナビ 18.99px はすべて normal で、書体のメトリクスに任せている。

実サイトの font-family は "あおとゴシック L" 1 つだけでフォールバックが無い。TypeSquare が落ちると UA 既定（多くの環境で明朝）になる。新規実装ではヒラギノ → 游ゴシック Medium → sans-serif を続けること。CSS にある "あおとゴシック B" / "あおとゴシック R" は配信されておらず可視 0 要素なので書かない。

07 / Responsive

本文は 4 幅すべて 16px

主ブレークポイントは max-width: 880px（--chg_width_hdr、実測 60 回）。1440 / 1200 / 834 / 375px のいずれでも body は 16px / lh normal / ls normal で、流体ルートもサイズ切替も無い。縮むのは見出しとレイアウトだけ。

Bootstrap 系の 575.98 / 767.98 / 991.98 / 1199.98px は VK Blocks 由来で自社の設計ではない。設計として追うのは 880px と 769px（--chg_width_cmn）と 480px の 3 つ。
