03 / Article

word-break: auto-phrase で文節ごとに折り返す

ほんとうにいいものを

body { word-break: auto-phrase } を書いている。日本語の文節単位で改行位置を決める値で、 <br> や <wbr> を手で入れずに「ほんとうにいい／ものを」のような不自然な折り返しを避けられる。 未対応ブラウザでは normal にフォールバックするだけなので、書いておいて損が無い。

  • コートを軸に、長く着られる日常着をつくる
  • 素材から仕立てまで、産地と職人に向き合う
  • 売り切る量を見極め、つくりすぎない

行頭記号は円ではなく 8px の横線。角丸を持たないこのサイトでは、点よりも線が馴染む。

04 / Links & Badges

面で塗った CTA ボタンが無い

押せるものはほぼ下線リンク。しかも下線は border-bottom ではなく background-image: linear-gradient(90deg, …) で引いてある（ホバーで左右に伸ばすため）。 面色のボタンは検索ボタン 1 つだけで、これがサイト内で唯一の角丸（0 3px 3px 0）になっている。

07 / Depth & Elevation

影が 1 種類、しかも inset

実測の box-shadow は 1 種類だけで、それが inset。 一般的なドロップシャドウを足さない——生成りの地の上では汚れて見える。

Level 0 — ほぼ全要素
box-shadow: none / border-radius: 0
Level 1 — 実測 28 要素
inset 1px 1px 0 0 #fff, inset -1px -1px 0 0 #fff
